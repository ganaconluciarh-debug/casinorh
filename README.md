# Royal Gold Casino - React + Vite

Sitio responsive de estilo casino, informativo y preparado para personalizar.

## Requisitos
- Node.js 18+
- npm

## Ejecutar
```bash
npm install
npm run dev
```

Luego abrir la URL que indique Vite (por defecto http://localhost:5173).

## Build de producción
```bash
npm run build
npm run preview
```

## Personalización
Editar `.env` para cambiar:
- Número de WhatsApp
- Mensaje inicial de WhatsApp
- Instagram
- Facebook
- Telegram

Los premios se modifican en:
`src/data/navigation.js`

Los estilos de cada componente están en su propio archivo CSS.
